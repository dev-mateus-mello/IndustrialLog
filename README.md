
# IndustrialLog

Sistema de registro e consulta de ocorrências operacionais desenvolvido em Python.

## Sobre o projeto

O IndustrialLog é um projeto de portfólio que busca facilitar o registro e a consulta de ocorrências em ambientes operacionais, permitindo manter um histórico organizado das atividades.

## Funcionalidades

- Registro de ocorrências.
- Identificação do responsável pelo registro.
- Consulta do histórico de ocorrências.
- Exibição de versão do sistema

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Como executar

1. Tenha o Python instalado.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```
